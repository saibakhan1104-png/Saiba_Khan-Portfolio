# Saiba Khan — Personal Portfolio

A responsive personal portfolio website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — layout, colors, responsive styling
- `script.js` — mobile navigation and current year

## Run locally
1. Extract the ZIP file.
2. Open the `saiba-khan-portfolio` folder.
3. Double-click `index.html` to preview it in a browser.

No build tools or package installation are required.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `saiba-khan-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.

## Personalize later
- Replace the initials illustration in the hero with your own portrait if you want.
- Add your LinkedIn profile and CV.
- Add project screenshots, repository links, and verified completion statuses.
- Review the project descriptions and technologies to ensure they accurately reflect your contribution.
